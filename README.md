# Sentinelle Pulse

Média d'analyse géopolitique, économique et de défense.
→ **[sentinellepulse.com](https://sentinellepulse.com)**

Plus de 250 articles de fond sur les dynamiques de pouvoir, les conflits
contemporains et l'économie politique, publiés en français.

## Ce que fait le site

- **Articles sourcés** : chaque analyse cite ses sources, rendues cliquables par
  une table de correspondance de plus de 70 institutions et publications.
- **Résumé par intelligence artificielle** : un condensé optionnel en tête
  d'article, généré à la demande.
- **Chronologie** : les mises à jour de chaque dossier rassemblées sur une
  frise, pour suivre un sujet dans la durée.
- **Carte mondiale** : entrée géographique dans les analyses, par région.
- **Dossiers thématiques** : regroupements transversaux aux quatre rubriques.
- **Assistant conversationnel** disponible sur toutes les pages.

## Rubriques

Géopolitique · Défense · Économie · OSINT

## Pile technique

Next.js 16 en App Router, TypeScript, Tailwind CSS 4, graphiques Recharts,
déploiement Vercel. Rendu côté serveur, données structurées schema.org sur
chaque article, flux RSS.

## Pourquoi c'est public

Le dépôt est ouvert pour montrer la façon dont le site est construit : le
rendu Markdown vers HTML avec sources cliquables, la génération des
métadonnées et des données structurées, et l'organisation éditoriale. Le
contenu des articles reste la propriété de son auteur.

## Projet frère

**[Sentinelle Pulse Copilot](https://copilot.sentinellepulse.com)** : annuaire
